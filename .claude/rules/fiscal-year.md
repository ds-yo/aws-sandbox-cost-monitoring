# 年度（Fiscal Year）ルール

- 年度は **4月1日開始・翌年3月31日終了**。
- 年度の呼称は **開始年** を使う。例: `FY2026` = 2026-04-01 〜 2027-03-31（= 2026年度）。
- 1〜3月は前年の年度に属する。例: 2027-02 は `FY2026`。
- 年度の判定・期間計算は必ず `scripts/fiscal.py` の関数（`fiscal_year_of` / `fiscal_year_range` など）を使う。手計算・独自実装をしない。
- 「経過月数」は年度開始月から対象月までの月数（対象月を含む）。例: 対象月 2026-09 → 6/12ヶ月。
- Cost Explorer の `TimePeriod.End` は **排他的（その日を含まない）**。年度末は `2027-04-01` を End に指定する。
